# EsShopAngularTrail

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.3.5.

## How to run project

1. Clone or download the project

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-project-folder>
```
2. Install dependencies
```bash
npm install
```
3. You’ll need to start two servers — the Angular frontend and the JSON backend.
### Backend (JSON Server)
Starts the mock backend using json-server on port 3000.
```bash
npm run backend
```
### Frontend (Angular)
Runs the main Angular app on http://localhost:4200:
```bash
npm start
```
or
```bash
ng serve
```
